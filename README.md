# VyxelCore Lite

Projeto final em Python para calcular custos e preços de venda de peças produzidas por impressão 3D.

## Arquivos

- `calculadora_3d.py`: programa principal.
- `test_calculadora_3d.py`: testes automatizados com pytest.

## Executar o programa

```bash
python calculadora_3d.py
```

## Executar os testes

```bash
pytest
```

## Primeira etapa concluída

- Funções de cálculo.
- Validação básica de entradas.
- Resumo do orçamento.
- Testes automatizados.
